# Conlang Workshop

A personal conlang notebook for tracking:
- vocabulary and lexical roots
- phonology and sound patterns
- grammar and sentence structure
- writing systems and script notes
- worldbuilding and culture context
- multiple conlangs with their own notes

This site is a single-page workshop built for quick local use in the browser. It stores your data in browser local storage so you can keep expanding it without a backend.

Open `index.html` in a browser to use it.
